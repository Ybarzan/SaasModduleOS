## 📌 PROCHAINES ÉTAPES IMMÉDIATES

1. **Démarrer le backend** (si pas fait)
   ```bash
   cd backend && ./mvnw spring-boot:run
   ```

2. **Tester l'authentification**
   - Créer un compte
   - Se connecter
   - Vérifier le token JWT

3. **Tester le calculateur**
   - Aller sur /simulation
   - Cliquer sur un Incoterm
   - Remplir les paramètres
   - Cliquer sur "Calculer"
   - Sauvegarder la simulation

4. **Vérifier le dashboard**
   - Voir l'historique des simulations
   - Tester la suppression

## 🎯 CE QU'ON A RÉGLÉ

### 🔧 Backend

| Problème | Solution |
|----------|----------|
| Routes mal configurées (manque `/v1/`) | Ajouté le préfixe `v1` dans `api.ts` |
| Clé token différente (`token` vs `userToken`) | Uniformisé sur `userToken` |
| **IncotermController manquant** | Créé le controller avec l'Enum |
| Token envoyé sur des routes publiques | Retiré pour register/login |

### 🎨 Frontend

| Problème | Solution |
|----------|----------|
| Pas de service d'auth | Créé `authService.ts` |
| Pas d'intercepteur global | Ajouté dans `main.tsx` |
| Mauvaise URL API | Corrigé `API_URL` vers `/v1` |
