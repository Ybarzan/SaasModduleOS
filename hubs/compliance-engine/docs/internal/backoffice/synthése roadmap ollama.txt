Synthèse - Problème JWT sur IncoKalk Backend
Le problème
Token JWT toujours considéré comme invalide (Token valid: false) → Erreur 403 Forbidden sur toutes les routes /api/v1/simulate/** et /api/v1/incoterms.
Cause racine
1. Le fichier bdkey.env contenait JWT_SECRET=110861 ( seulement 6 caractères)
2. HMAC-SHA256 exige ** minimum 32 caractères (256 bits)**
3. Quand la clé est trop courte, Keys.hmacShaKeyFor() échoue → tous les tokens invalidés
4. Le fichier bdkey.env n'était jamais chargé par Spring Boot lors du mvn spring-boot:run
