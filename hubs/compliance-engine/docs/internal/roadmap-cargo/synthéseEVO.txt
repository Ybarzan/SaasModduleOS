Approche

Pattern de test (déjà établi dans le projet)

- Mockito pur (pas de @SpringBootTest, pas de H2) — ~46 fichiers existants suivent ce pattern
- Mocks : @Mock sur les repositories, @Mock sur les services tiers (Stripe, RestTemplate, etc.), @InjectMocks sur le service testé
- Setup : @BeforeEach avec MockitoAnnotations.openMocks(this) + UUID.randomUUID() pour les IDs + entités construites via builders
- Assertions : AssertJ (assertThat(...).isEqualTo(...), assertThatThrownBy(...).isInstanceOf(...))
- TenantContext : mocké via try (MockedStatic<TenantContext> ctx = mockStatic(TenantContext.class)) { ctx.when(TenantContext::get).thenReturn(companyId); ... } — pattern vu dans FinancialReportingServiceTest
- Champs @Value : injectés via ReflectionTestUtils.setField(service, "fieldName", value) — pattern vu dans NotificationServiceTest
- SDKs statiques (Stripe) : mockés via MockedStatic<Stripe> ou MockedStatic<Session> — pattern générique Mockito
- Frameworks utilisés : JUnit 5 (@Test, @DisplayName, @BeforeEach), AssertJ, Mockito, Spring ReflectionTestUtils

Structure de chaque fichier de test

@DisplayName("XxxService — Tests unitaires")
class XxxServiceTest {

    @Mock Repo1 repo1;
    @Mock Repo2 repo2;
    // ...autres dépendances
    @InjectMocks XxxService service;

    UUID companyId, entityId;
    Company company;
    Entity entity;

    @BeforeEach
    void setUp() {
        MockitoAnnotations.openMocks(this);
        ReflectionTestUtils.setField(service, "configKey", "value"); // si @Value
        companyId = UUID.randomUUID();
        entityId = UUID.randomUUID();
        company = Company.builder().id(companyId).build();
        entity = Entity.builder().id(entityId).company(company).build();
    }

    // ── méthode1 ────────────────────────────────────────
    @Test @DisplayName("...")
    void methode1_happyPath() { ... }

    @Test @DisplayName("...")
    void methode1_notFound() { ... }
}
